# DSp Free for Haval Dargo — DargoSplit 3.6

`DargoSplit` is an Android head-unit APK and phone installer bundle for Haval Dargo. Install DSp Free on the car multimedia system using ADB from a laptop, USB OTG from an Android phone, or Bugjaeger. The guide covers USB Peripheral mode, Windows ADB drivers, and installation commands.

`DSp Free` для Haval Dargo: APK для Android-ГУ и инструкции по установке через ADB, USB OTG и Bugjaeger.
Комплект для установки DSp 3.6 на головное устройство Haval Dargo.

## Состав

- `01_Headunit/DSp-free-3.6.apk` — само приложение для ГУ. Для установки напрямую используйте ADB.
- `02_Phone/DSp-free-installer-3.6.apk` — приложение-установщик для Android-телефона; внутри него лежит head-unit APK 3.6.
- `03_Laptop/platform-tools_r37.0.0-win10-11.zip` — Android Platform Tools для Windows, включая ADB.
- `03_Laptop/usb_driver.zip` — USB-драйвер из предоставленной папки `Ноут`.
- `04_PhoneTools/Bugjaeger-Premium-8.0-user-supplied.apk` — предоставленный пользователем APK Bugjaeger.

## Установка с ноутбука по USB и ADB

1. Распакуйте комплект на ноутбуке и откройте PowerShell в папке `DargoSplit`.
2. Распакуйте Platform Tools:

   ```powershell
   Expand-Archive -LiteralPath '.\03_Laptop\platform-tools_r37.0.0-win10-11.zip' -DestinationPath '.\03_Laptop\platform-tools' -Force
   $adb = Get-ChildItem '.\03_Laptop\platform-tools' -Filter adb.exe -Recurse | Select-Object -First 1 -ExpandProperty FullName
   ```

3. Переведите USB-порт ГУ в режим `Peripheral` через инженерное меню Dargo:
   - на ГУ откройте `Настройки системы` → `Системная информация` → `Software Information`;
   - несколько раз нажмите строку `Версия ПО`, пока не появится поле сервисного пароля;
   - введите `*#4435ab`;
   - в инженерном меню откройте `Software Information`, найдите `HW Version` и нажимайте на неё, пока не появится поле второго пароля;
   - введите `aZ10&*+30`;
   - в разделе `Others` установите `USB mode` → `Peripheral`.
4. Подключите USB-порт ноутбука к USB-порту ГУ кабелем передачи данных. Если Windows не видит устройство ADB, распакуйте `usb_driver.zip`, откройте Диспетчер устройств и установите драйвер для обнаруженного устройства Android/ADB.
5. Проверьте подключение и подтвердите запрос отладки на экране ГУ, если он появится:

   ```powershell
   & $adb devices -l
   ```

   В списке должно быть устройство со статусом `device`. Если список пуст или статус `unauthorized`, проверьте кабель/USB-режим и подтвердите диалог на ГУ.
6. Установите APK:

   ```powershell
   & $adb install -r '.\01_Headunit\DSp-free-3.6.apk'
   ```

   `Success` означает, что Package Manager принял APK. Если установка сообщает о несовпадении подписи, существующую версию DSp нельзя обновить этой сборкой поверх неё: сначала сохраните нужные настройки и удалите старую версию штатным способом, затем повторите установку.
7. После установки верните `USB mode` в `Host`, если USB-порт нужен для флешек и аксессуаров.

### Если ГУ подключено к ADB по сети

Подключите телефон/ноутбук и ГУ к одной локальной сети. Используйте IP и порт, которые реально показывает/принимает ГУ; порт `5555` не включён автоматически на каждом устройстве:

```powershell
& $adb connect IP_ГУ:ПОРТ
& $adb devices -l
& $adb -s IP_ГУ:ПОРТ install -r '.\01_Headunit\DSp-free-3.6.apk'
```

Не открывайте ADB в интернет. Для первичной установки сетевой ADB должен быть включён на ГУ заранее.

## Первичная установка с телефона по USB

Телефонный APK — отдельная программа-установщик. Она устанавливается на телефон, а DSp из неё передаётся на ГУ.

1. Скопируйте `02_Phone/DSp-free-installer-3.6.apk` на Android-телефон и откройте его в файловом менеджере.
2. Разрешите установку из этого источника, если Android попросит, и завершите установку `DSp Free Installer`.
3. Откройте приложение и выберите пункт установки DSp по USB. Следуйте показанным там шагам. На штатном меню Dargo последовательность может отличаться по версии прошивки:
   - на ГУ откройте `Настройки системы` → `Системная информация` → `Software Information`;
   - несколько раз нажмите `Версия ПО`, чтобы открыть ввод сервисного пароля;
   - введите `*#4435ab`;
   - в инженерном меню откройте `Software Information`, найдите `HW Version` и нажимайте её, пока не появится запрос второго пароля;
   - введите `aZ10&*+30`;
   - в разделе `Others` измените `USB mode` на `Peripheral`.
4. На телефоне подключите USB-C OTG-переходник (USB-C male → USB-A female). Соедините его с USB-портом ГУ кабелем USB-A↔USB-A передачи данных.
5. Если Android спросит, какое приложение открыть для USB-устройства, выберите `DSp Installer` и подтвердите. Держите экран телефона включённым до завершения установки.
6. После успешной установки отсоедините кабель и обязательно верните USB-режим ГУ в `Host`.

В режиме `Peripheral` флешки могут временно не работать. Переключайте USB-режим только через известный пункт инженерного меню и верните `Host` после установки. Если USB-устройство не появляется, не форсируйте соединение: проверьте OTG-переходник, data-кабель и поддержку USB Peripheral конкретной версией ГУ.

## Установка с телефона через Bugjaeger по USB

Bugjaeger работает как ADB-клиент с телефона. APK устанавливается на ГУ, если телефон подключён к ГУ по USB-OTG и ADB-соединение установлено именно с ГУ.

1. Установите `04_PhoneTools/Bugjaeger-Premium-8.0-user-supplied.apk` на телефон. Если Android запросит разрешение на установку из этого источника, разрешите его для файлового менеджера и завершите установку.
2. Скопируйте `01_Headunit/DSp-free-3.6.apk` во внутреннюю память телефона, например в папку `Download`.
3. На ГУ выполните ту же последовательность входа в инженерное меню, что и в разделе выше, и установите `Others` → `USB mode` → `Peripheral`.
4. Подключите к телефону USB-C OTG-переходник (USB-C male → USB-A female). Соедините его с ГУ кабелем USB-A↔USB-A передачи данных.
5. Запустите Bugjaeger. Откройте USB-подключение/список USB-устройств и выберите обнаруженное устройство ГУ. Если Android покажет системный запрос на доступ к USB-устройству, подтвердите его. Если ГУ запросит разрешение на отладку, подтвердите его на экране ГУ.
6. Убедитесь, что Bugjaeger показывает подключённое устройство. Затем откройте в приложении раздел `Packages` или `Package Manager`, выберите действие установки APK (`Install APK` или значок `+`), найдите файл `DSp-free-3.6.apk` в `Download` и запустите установку. Точное название пункта зависит от сборки Bugjaeger.
7. Дождитесь сообщения об успешной установке в Bugjaeger и проверьте, что DSp появился в списке приложений ГУ.
8. Отсоедините кабель и верните USB-режим ГУ в `Host` через инженерное меню.

Если USB-устройство не появляется в Bugjaeger, проверьте, что ГУ в режиме `Peripheral`, OTG-переходник поддерживает USB Host на телефоне, а кабель передаёт данные. Если пункта USB-подключения в вашей модифицированной сборке Bugjaeger нет или устройство не определяется, используйте встроенный USB-установщик DSp либо ноутбук с ADB.

## Установка/обновление с телефона по Wi-Fi

Этот способ требует, чтобы DSp уже был установлен и запущен на ГУ.

1. Установите `DSp-free-installer-3.6.apk` на телефон.
2. Подключите телефон и ГУ к одной Wi-Fi сети или к точке доступа телефона. У телефона должен быть доступ к локальной сети; разрешите его для DSp Installer. Временно отключите VPN/фильтр локальной сети, если поиск ГУ не работает.
3. Запустите DSp на ГУ, затем откройте DSp Installer на телефоне и запустите поиск/подключение к ГУ.
4. Выберите обновление/установку и дождитесь завершения. Если DSp на ГУ ещё не установлен, используйте первичную установку по USB или ноутбук с ADB.

## Bugjaeger

Bugjaeger — дополнительный ADB-клиент, не телефонный DSp Installer. Его APK в комплекте взят из пользовательской папки `Телефон`; это сторонняя модифицированная сборка, её происхождение и безопасность отдельно не проверялись. Для установки DSp проще использовать DSp Installer по USB/Wi-Fi или ADB-команду с ноутбука.
